# The Chase

Un jeu d'horreur entre amis.

**Pour jouer :** télécharge [TheChase-Launcher.exe](https://github.com/Celombor/the-chase-releases/releases/latest/download/TheChase-Launcher.exe),
place-le dans un dossier à toi (pas dans Program Files) et lance-le. Il installe le jeu puis le garde à jour automatiquement.

Si Windows SmartScreen bloque le launcher : « Informations complémentaires » puis « Exécuter quand même ».
