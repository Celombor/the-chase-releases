# The Chase

Un jeu d'horreur entre amis.

**Pour jouer :** télécharge et lance [TheChase-Setup.exe](https://github.com/Celombor/the-chase-releases/releases/latest/download/TheChase-Setup.exe).
Choisis où installer le jeu, puis le launcher le télécharge et le garde à jour automatiquement (lui-même compris).

Si Windows SmartScreen bloque l'installateur : « Informations complémentaires » puis « Exécuter quand même ».

Déjà le launcher 2.0 ? Lance quand même l'installateur une fois : il propose de reprendre ton dossier de jeu existant.
